# Data seams between the prototype surfaces and the control plane

The surfaces in `apps/surfaces` are byte-identical to the prototype. Everything below is applied at serve
time by `App\Http\Support\SurfaceRenderer` (cached per file version) or lives in `apps/surfaces/api/*`.
No seam changes typography, tokens, spacing, components or navigation (template-inventory §6).
