# Glossary

| Term | Meaning in ONHOST |
| --- | --- |
| CommandBus | The only entry point for state-changing application commands. |
| NORMAL / HIGH / CRITICAL | Risk levels; HIGH requires fresh step-up and CRITICAL also requires four-eyes approval. |
| Outbox | Durable event publication boundary used through `GenericEvent::of`. |
| Provider adapter | Vendor-specific implementation behind an ONHOST contract. |
| Surface | Preserved customer/staff prototype rendered through controlled data seams. |
| Money | Value object containing integer minor units and currency. |
| Four-eyes | A second authorized human approves a critical action. |
| Brain | Repo-native context, scripts, and client configuration; it has no production authority. |
| Generated context | Reproducible summaries in `docs/generated`; never hand-edited. |
