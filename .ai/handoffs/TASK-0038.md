## Outcome

`php artisan onhost:forensics:lookback [--since] [--until] [--source=*] [--json]` is a strictly read-only report
(permission program P0-01 / IF-0, D16). For each verified exploit of Phase 0 it gives the tables it checked and their
row counts, the hits (each with `confirmed`, `possible` or `attempt`), the unknowns (what the database cannot tell,
and which tool can), the notes and the fixed limits. Exit codes: 0 when there are no hits, 1 when there are hits,
2 for bad options.

| Source key | Exploit | What it reads |
| --- | --- | --- |
| `owner_demotion` | TD-1 | invitations accepted by the current owner at a lower role, the attach/change-role audit, the owner's current membership |
| `game_panel_identity` | PA-01 | `provision.game` operations (`ptero_user_created`), bindings, `game_servers`: a panel user created for org A under org B's service |
| `discord_after_removal` | G1 | `organization.member.remove` audit vs `discord_links.last_used_at` and `discord-bot` audit rows |
| `aapanel_outside_root` | PA-02 | `service.action` file/cron operations and audit vs the site root in `provider_bindings.meta.path` |
| `token_cross_org` | PA-04 | audit rows with `session_id = token:<id>` whose token belongs to another organization |
| `staff_own_org` | SS-1/SS-5, EXPL-1..3 | staff hold lifts and forced purges on organizations the staff user is a member of |
| `partner_payouts` | P1/P2 | payout amount vs the commissions allocated to it; IBAN not used by any earlier paid payout |

It runs SELECTs only, inside a transaction that is always rolled back. It uses no CommandBus, adapter, HTTP, file,
route, schedule or event. Output goes to stdout only. The output has no e-mail addresses and no full IBANs, and for
PA-02 it shows only the offending paths.

The runbook `docs/runbooks/breach-register.md` covers:

- running it on production or on a restored copy, keeping the output private and hashing it;
- how to read the verdicts, with a follow-up per source;
- recording findings in the cyber incident (`POST /v1/staff/security/incidents`, evidence by sha256) with a register
  entry template that includes the owner decision line;
- Art. 33 (ÚOOÚ, 72 h) and Art. 34 notices as DRAFT only. Neither is sent, and the `GDPR_72H` timer is neither
  submitted nor waived, without the owner's recorded decision (§10 O3). An AI session never sends them.
