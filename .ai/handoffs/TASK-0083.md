# TASK-0083 handoff: task start stores each path separately

Cause: `brain.ps1` forwards remaining arguments as `[string[]] $Rest`; `-Paths a,b,c` typed inside a PowerShell session
is stringified with spaces ("a b c"), and task.ps1 split only on commas, so the lock stored ONE joined string and the
overlap check never matched it (phase D: two tasks both locked bootstrap/app.php).

Fix: `ConvertTo-OnhostPathList` (scripts/ai/common.ps1) splits on commas, semicolons, whitespace and newlines, trims,
drops empties and dedupes. Used by `task.ps1` for `-Paths` (start and claim), the claim merge, and `Find-Overlaps`
(both the wanted list and the held paths, so locks already written as one joined string still block).

Limit: a path containing a space cannot be given; split on whitespace is deliberate.

Tests: `scripts/ai/tests/Orchestration.Tests.ps1` (normaliser shapes, old joined lock, comma list overlap). Three of
them fail against the old task.ps1.
