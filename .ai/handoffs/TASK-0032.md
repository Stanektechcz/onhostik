## 27. The release tool never runs the site's code as root

`/etc/onhost/app.env` is root:www 0640 and the site user can write the site tree, so root executing anything from that
tree — artisan, composer and its scripts, a cached config — turns a compromise of the site user into root. The gated
deployer (`infra/aapanel/deploy.sh`) and `install.sh` run every artisan and composer call as the site user through
`setpriv` with a clean environment and refuse a host where that cannot happen; root keeps git — only on its own
repository outside the site tree (`GIT_DIR`; a `.git` in the tree could be replaced by the site user after any check and
carry config, attributes and hooks root's git would obey — review round 2) —, the rename of `VERSION` into the site
root and the hand-over of what its checkout wrote into storage/bootstrap/cache (only entries not the site user's, each
by `-execdir chown -h` from inside its directory; `-exec chown -h` over batched paths resolved the directories in the
middle at chown time — review round 2), and never writes by path below the site root (a directory there can be a link
the site user planted). Files an older root run left there are reported and refused, not re-owned. `vendor/` belongs to the site user. Test: `tests/Feature/Platform/DeployGateTest.php`
(*runs every artisan and composer call as the run user …*, *installs with the site's PHP run only as the run user …*).
The site's code runs in a session of its own (`setsid --wait`) with stdin from `/dev/null`, and neither script lets
anything it starts hold root's terminal (only root's own `cat` writes to it): otherwise the site user's code could push
keystrokes into root's shell (TIOCSTI, CVE-2016-2779's class) or read what root types next (TASK-0032, second review
round 1; *gives the site's PHP its own session …*). Hand-run artisan in the staging runbook goes through the same
wrapper (`www`). Residual: git's checkout still writes into the writable tree, and the hand-over of what it wrote relies
on `fs.protected_hardlinks=1` (a root-owned code tree removes both). Tests: *runs git only on root's repository …*,
*re-owns nothing in a tree the run user already owns …*.
