  staff list); PHP runs the first arm only, so staff were never told. Original intent (`git log -S`: d49a8ab H458, f246399
  H447, b81f560 H456/H467, and `docs/architecture/events-catalog.md`): "customer + operator" for all four.
- C4: decision 7 leftover — `eshop/shop-peak` still sells `php_workers_dedicated` ("24 PHP workerů (dedikované)") on aaPanel,
  where one PHP pool serves the whole node; TASK-0023's `PlacementRules` could not move it to ISPConfig (WAF rate limit,
  client-wide site count) and left it as "owner decision pending". Decision: the next catalogue revision (TASK-0022
  `CatalogRevisions`, operator command `onhost:catalog:revise`) publishes new versions without it.
