## Objective

`.\brain.ps1 task start` finishes (task file committed, lock saved, board updated) even though composer writes its
progress to stderr.

## Context

Under Windows PowerShell 5.1 with `$ErrorActionPreference = 'Stop'`, `& $php $phar install ... | Out-Host` turns the
first stderr line ("Installing dependencies from lock file") into a terminating `NativeCommandError` whenever stderr
is redirected (agent shells, `2>&1`, CI). `start` then halts after `git worktree add`: no task file, no lock, no board
entry. Reproduced while opening this very task; the task file and lock were completed by hand (`composer install` +
`task claim`).
