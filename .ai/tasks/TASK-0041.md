## Findings

- N1 NOTE `app/Http/Controllers/Api/V1/DomainController.php` — the bus fingerprint could not live in the controller: the handler
  passes the same key to DomainService, whose operation key (and 409) must stay body-independent. Resolved by the DomainCommand
  override (scope extension above), as TASK-0036 did for ServiceActionCommand.
- N2 NOTE `domains/Provisioning/Scheduling/NodeScheduler.php` — callers of `pick()` that name no organization are not judged:
  `WebMigrationWorkflow` (moving a site to another aaPanel node) and `CartCapacity::fits` (the cart). Not in this task's paths;
  see Concerns.
- N3 NOTE `providers/AaPanel/AaPanelTransport.php` — the site's agent name comes from the transport's `siteWriter` closure
  (`AaPanelTools::readyAgent`), which may run `id -u` (cached 10 min) or `ensureAgent` on the node before a site download.
