### Review round 1 (onhost-security)

- R1-1 MEDIUM `domains/Provisioning/Workflows/WebMigrationWorkflow.php` targetStep, `ServiceMigrationService::evacuate` — the
  staff/CLI move bypassed (a): a named `target_node_id` skipped the pick, an automatic pick named no organization, so
  `service.evacuate` of an aaPanel node could put several organizations on one open node. **RESOLVED (in this task, scope
  extended to the target step):** the target step runs under `NodeScheduler::underPlacementLock` (the node-row lock `place()`
  already took), passes `organization`/`except_service` to the automatic pick, judges a named node with `sharedNodeRefusal`
  (refused, not retried, detail `{node, tenancy: open}`), and records its target facts in the operation context before the
  lock is released. The reviewer's finding went further than stated: even with the organization passed, a move switches the
  service to the target only after the copy, so each move of one evacuation saw the empty open node empty. Therefore
  `sharedNodeRefusal` also counts a `web.migrate` operation that is not over and recorded `target_instance_id` as its
  organization on that node — for the next move and for an order (`place()`) alike. `ServiceMigrationService` is unchanged:
  the workflow is where the target is decided (also for windows that start days later); a refused move fails with the node
  and `onhost:aapanel:tenancy --apply --instance=` in its error, on the operations board and in `service.migration.failed`.
  Tests: `refuses a staff move … named or picked` (2 rows), `counts a move already heading for an empty open node …`.
- R1-2 MEDIUM `providers/AaPanel/AaPanelTransport.php` ownOwners, `providers/AaPanel/AaPanelTools.php` transportAt — the download
  pattern read the agent from `siteWriter` = `readyAgent`, so a READ on an open node could run `useradd -G www` and a recursive
  `setfacl` as root (e.g. re-creating the agent of a terminated service while its final archive is downloaded). **RESOLVED:**
  the transport gets the agent's NAME as a new optional argument `$siteAgent` (`Naming::prefix(serviceId).'ag'`, '' without a
  service id); `ownOwners()` never calls `siteWriter`. A name nobody holds matches no `stat -c %U` owner, so a missing agent
  narrows to `www` by itself. `siteWriter` / `readyAgent` stay for writes on a closed node (TASK-0034) only. Scope extended to
  `AaPanelTools::transportAt` (one argument). Test: `names this site's agent for a download … no useradd, no setfacl, no id -u`;
  the (e) contract test's transport now throws if readiness is ever asked.
