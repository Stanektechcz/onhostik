## Acceptance criteria

- [x] GPC: only accounting code 2 (credit); amount in hellers 49–60, VS 62–71, posting date 123–128 (value date 92–97 fallback),
      counter-account and Windows-1250 name; debit and reversal lines skipped and counted.
- [x] camt.053: only booked (`BOOK`) credit (`CRDT`) non-reversal entries; a batch entry → one line per `TxDtls` with its own amount;
      VS from `Strd/CdtrRefInf/Ref`, then `/VS/…` in `EndToEndId`, then `VS …` in `Ustrd`.
- [x] Idempotence: the same file again → 0 recorded, all duplicates, nothing paid twice (wallet checked).
- [x] Permission: 403 for a customer and for staff without `billing.reconcile` (checked before the file is read and again in the bus).
- [x] XXE / billion laughs / a DOCTYPE hidden by UTF-16: refused before parsing (`bank_statement_unsafe`); `LIBXML_NONET`, no
      `LIBXML_NOENT`, no DTD load; the parsed document must have no doctype.
- [x] Limits: 2 MB (validation + parser), 5000 lines (`bank_statement_too_long`); CSV / unknown → `bank_statement_format`; a malformed
      `075` → `bank_statement_gpc`; nothing recorded on any refusal (the bus runs the import in one transaction).
- [x] The file content is never stored or audited (only sha256, size, file name, counts).

## Security self-check (ecc:security-reviewer style)

- Input: untrusted file, parsed only after authorization; strict amount/currency/date validation; no XPath built from input; simple
  regexes (no nested quantifiers).
- XML: DOCTYPE/ENTITY/NUL/unexpected-encoding refusal before libxml, `LIBXML_NONET`, external entity loader off by default (PHP 8),
  post-parse doctype check. GPC is fixed-width substr on bytes; the name is converted with `iconv` (`//IGNORE`).
- Money: only credits; `record()` unchanged (unique `external_id`, VS + amount + currency matching, amount mismatch → reconciliation
  item); the importer cannot debit or refund anything. A finance user with `billing.reconcile` can already record any line by hand —
  the file adds no new power, every line is audited.
- Secrets/PII: no file stored, content stripped from the command audit; counterparty names stored as for Fio/manual lines.
- Findings: none MEDIUM+ open.
