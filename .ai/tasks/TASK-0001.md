- HIGH `scripts/ai/gate.ps1` — Pest exit code ignored when a JUnit file existed (security reviewer); MEDIUM same

  crash of the gate on the empty report, fixed).

- MEDIUM read-only agents still have Bash; LOW Read-tool denies can be bypassed through Bash. **Mitigated:**
