## Objective

A card payment whose provider notification and payer return were both lost no longer stays pending for good: every ten
minutes `onhost:payments:sweep` re-reads the provider's status of card intents still open (between a grace period and a
cut-off) and settles, fails or cancels them through the existing idempotent `PaymentService::syncFromProvider`.

## Context

W0 finding: `PaymentService::reconcile()` has no caller and nothing is scheduled, yet the comment in `handleWebhook` counts on
a "daily reconciliation". W1 (PR #223, not merged) makes an empty Comgate IP allow-list refuse every notification until the
owner supplies it, so the payer's return is the only settlement path until then. Lesson of TASK-0222: a missing vault secret
throws a plain `RuntimeException`, which must not fail the scheduled job every run (doctor row "every scheduled job ran
within its budget"; staging has no Comgate credentials).

## Contracts affected

New artisan command `onhost:payments:sweep {--limit=}` scheduled every ten minutes (new schedule budget 1800 s). New config
keys `onhost.payments.sweep.{providers,grace_minutes,max_age_hours,batch}` (env `ONHOST_PAYMENTS_SWEEP_*`). Provider calls:
only the existing status read (`getPaymentStatus`) through `syncFromProvider`. No schema, no events beyond the existing ones.

## Acceptance criteria

- [ ] an open card intent (CREATED / PENDING_CUSTOMER / AUTHENTICATION_REQUIRED / PROCESSING, provider id known) older than the
      grace period and younger than the cut-off is re-read and settled when the provider says paid
- [ ] intents inside the grace period, past the cut-off, of the bank provider, or already final are not touched (no provider call)
- [ ] the batch is capped per run, oldest first
- [ ] one intent's provider error does not stop the others; the log has only the intent id, the provider and the exception class
- [ ] a provider without credentials is skipped with a warning; the command exits 0 (staging has no Comgate credentials)
- [ ] one-line summary: checked / settled / failed / open / errors / skipped
- [ ] scheduled `everyTenMinutes()->withoutOverlapping()->onOneServer()`; schedule budget snapshot updated
- [ ] stale "daily reconciliation" comment in `PaymentService::handleWebhook` fixed; Comgate runbook names the sweep
