## Objective

What outcome the user gets, in one or two sentences.

**Package identity (decisions 14, 15).** A password change revokes every personal API token of the user in every organization;
the changing browser stays signed in, service-account tokens and integration secrets are untouched, an operator switch restores
the old path. The game panel account password (`panel.password`) is set by the organization owner alone.

**Package credit-orders (decision 20).** Account credit is spent by the organization owner and the billing admin only
(`billing.wallet.spend`). A credit-paid order (wallet, postpaid) placed by anybody else waits for their approval (nothing
reserved, documented or provisioned; approve pays it from credit, reject or expiry cancels it without a charge). Paying from
credit at once (invoice from credit, domain renewal, marketplace order, approving paid support work, archive download fee) is
refused to anybody else with a Czech message saying whom to ask. Card and bank payments are unaffected. Behind
`ONHOST_ORDER_CREDIT_APPROVAL` (default off).
