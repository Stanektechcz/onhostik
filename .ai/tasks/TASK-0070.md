## Security considerations

- Self-service command without permission (like AcceptInvitation): the handler acts only on the caller's rows; ids of others answer 404.
- `keep` (current row) comes from the server-side session, never from the request. Token principals refused three times (TokenRouteScope, controller, handler).
- Ending a session rotates the remember token (one token serves all remembered browsers), so an ended browser cannot sign itself back in.
- The org choice is re-checked against a current membership on every request; header/query paths unchanged.
